# Calcul valoare energie produsa/consumata bazat pe preturile din PZU

1. Extragere preturi PZU: modificati anul si luna pentru care vreti sa faceti extragerea si apoi rulati scriptul extragere_preturi_pzu.py
2. Calcul valoare energie cumparata sau vanduta: pregati curbele de consum si/sau de productie pentru care doriti sa faceti calculul. Modificati in scriptul calcul_valoare_energie.py numele fisierelor pentru care doriti sa faceti calculul: fisierul cu preturile PZU si fisierele cu curbele de productie si/sau consum. Apoi rulati scriptul.
